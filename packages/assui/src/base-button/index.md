### 1.2. API

| 属性名   | 描述       | 类型                                   | 默认值   |
|----------|------------|----------------------------------------|----------|
| color    | 按钮颜色   | `primary` \| `success` \| `dark` \| `gray` \| `default` | `default` |
| variant  | 按钮样式   | `outlined` \| `dashed` \| `link`       | `none`   |
| size     | 按钮大小   | `small` \| `medium` \| `large`         | `medium` |
